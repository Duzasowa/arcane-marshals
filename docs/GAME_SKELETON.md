# Arcane Marshals — скелет гри

_Створено: 2026-11-23. Структуру взято за зразком HoMM5, вміст свій. Правила й числа — у `docs/MECHANICS.md`._

## 1. Потік гри
```
Головне меню ─┬─ Нова гра ── Налаштування партії ── [генерація карти] ──┐
              ├─ Завантажити ───────────────────────────────────────────┤
              ├─ Налаштування                                           │
              └─ Вихід                                                  ▼
                                                     ┌──── Пригодницька карта ◄───────┐
                                                     │      │   │   │   │             │
                                        Екран героя ◄┘      │   │   │   └► Обмін героїв │
                                                  Екран міста   │   └► Діалог об'єкта   │
                                                  (найм, будівлі,   │                   │
                                                   таверна, ринок,  ▼                   │
                                                   гільдія магів)  Бій ── Результат бою ┘
                                                                     (рівень героя → вибір навички)
                     Кінець ходу → наступний гравець (hotseat: екран «Передайте хід») / ШІ
                     Умова перемоги → Екран кінця гри → Головне меню
```

## 2. Екрани та їхні елементи

### 2.1 Головне меню
Нова гра, Завантажити, Налаштування, Автори, Вихід. Фон — 3D-сцена або арт.

### 2.2 Налаштування партії
- Шаблон карти (зі списку) і розмір; сід (поле + «випадковий»).
- Слоти гравців (2–4): людина / ШІ (складність) / закрито; фракція; колір; стартовий герой (або випадковий);
  стартовий бонус (золото / артефакт / ресурс).
- Складність (стартові ресурси, сила нейтралів).
- Умова перемоги: знищити всіх / захопити місто / протриматися N тижнів (v1: перша).

### 2.3 Пригодницька карта (головний екран)
- **3D-карта** з камерою під кутом: панорама (WASD / край екрана), зум, поворот на 90°.
- **Верхня смуга:** ресурси (золото, дерево, руда, кристал), день / тиждень / місяць.
- **Права панель:** список героїв (портрет, смужки руху й мани), список міст, кнопка «Кінець ходу».
- **Мінікарта** з туманом війни.
- **Шлях героя:** клік — показ маршруту зі стрілками (зелені — сьогодні, жовті — наступні дні), повторний клік — рух.
- **Підказки при наведенні:** об'єкт, армія з оцінкою кількості («кілька», «зграя», «орда»), власник.
- **Діалоги об'єктів:** скриня (золото чи досвід), нейтрали (битися / відкупитися / приєднати), святилище, шахта (захоплено).
- **Журнал подій** (звіт за день).

### 2.4 Екран міста
- 3D або 2D-вид міста, де видно збудоване.
- **Будівництво:** сітка будівель із ціною, залежностями й позначками «можна / не вистачає / вже збудовано»
  (1 будівля на день).
- **Найм:** вікно житла (портрет істоти, доступно, ціна, повзунок кількості, «найняти все»).
- **Гарнізон і армія героя:** 2 ряди по 7 слотів, перетягування, розділення загону (Shift).
- **Гільдія магів:** список заклинань за рівнями; герой у місті вивчає їх автоматично.
- **Таверна:** 2 герої на вибір, найм. **Ринок:** обмін ресурсів.
- **Огляд міста:** дохід за день, приріст за тиждень.

### 2.5 Екран героя
Портрет, клас, рівень і досвід; 4 атрибути; мораль і удача; навички з рівнями; перки; лялька з 6 слотами артефактів +
рюкзак; армія (7 слотів); книга заклинань; накази; спеціалізація.

### 2.6 Вибір навички при новому рівні
Діалог з 2 варіантами (іконка, назва, опис), атрибут, що зріс.

### 2.7 Обмін героїв
Дві армії й два набори артефактів поруч, перетягування.

### 2.8 Бій
- **3D-арена 12×10** з камерою під кутом, сітка поверх землі (показувати / ховати).
- **Шкала ініціативи** знизу: портрети наступних 10 ходів, при наведенні підсвічується загін.
- **Підсвітка:** досяжні клітинки, цілі для атаки, клітинка, з якої буде удар; курсор показує дію
  (рух / атака / постріл з позначкою «½»).
- **Прогноз удару** при наведенні: шкода мін–макс, скільки загине, чи буде контратака.
- **Панель дій:** Чекати, Оборона, Книга заклинань, Накази, Авто-бій, Втекти / Здатися, Налаштування (швидкість анімацій).
- **Панель загону** (при наведенні або виборі): параметри, здібності, ефекти з тривалістю.
- **Журнал бою** (розгортається).
- **Результат бою:** переможець, втрати обох сторін, досвід, здобич.

### 2.9 Збереження й завантаження
Слоти з датою, назвою карти, днем гри; автозбереження на початку ходу.

### 2.10 Передача ходу (hotseat)
Повноекранна шторка «Хід гравця Синій», щоб гравці не бачили чужий туман.

### 2.11 Кінець гри
Перемога / поразка, статистика (днів, битв, найсильніший герой), повернення в меню.

### 2.12 Налаштування
Гучність (музика, звуки), швидкість анімацій бою і руху ШІ, роздільна здатність / вікно, мова (укр / англ).

## 3. Системи та їхні зв'язки
```
Data (ресурси .tres): UnitDef, AbilityDef, SpellDef, OrderDef, FactionDef, HeroClassDef, HeroDef,
                      SkillDef, PerkDef, ArtifactDef, BuildingDef, MapObjectDef, MapTemplateDef
        │ (лише читання)
        ▼
Simulation (game/simulation, без нод, детермінована)
  GameState ── Players[] ── Heroes[] ── Army(7 слотів) ── Stack(unit, count, top_hp)
     │            └ Resources, Towns[], fog
     ├── AdventureMap (тайли, об'єкти, власники) ── PathFinder (A*, вартість руху)
     ├── Calendar (день/тиждень) ── WeeklyGrowth, DailyIncome
     ├── TownLogic (будівництво, найм)        ── HeroProgress (досвід, рівні, навички)
     ├── BattleState ── Grid, Stacks, AtbTimeline, DamageCalc, AbilityHooks, SpellCast, Orders, BattleResult
     ├── MapGenerator (шаблон + сід → AdventureMap)
     └── Commands (усі дії гравця/ШІ) ── CommandQueue ── StateHasher (digest)
        ▲                                   ▲
        │ команди                           │ команди
UI (game/ui) — екрани, кнопки         AI (game/ai) — бойовий і стратегічний, «гравець без UI»
        │ читає стан
View (game/view) — 3D-карта, 3D-арена, моделі юнітів, анімації, ефекти, звук
```
- **Бій** — окремий `BattleState`, що створюється з двох армій і повертає `BattleResult` (втрати, досвід, переможець).
  Його можна запустити в тестах і замірах без карти.
- **Збереження** = серіалізація `GameState` + сід + версія формату.

## 5. Ролі юнітів (скелет для кожної фракції)
Кожна фракція заповнює 7 рівнів, і ролі повторюються з варіаціями, щоб фракції були порівнянні:

| Рів. | Типова роль | Навіщо в армії |
|---|---|---|
| 1 | масовий дешевий | закриває клітинки, «м'ясо», бере контратаки |
| 2 | стрілець | постійна шкода здалеку, ціль для ворожих літунів |
| 3 | танк | тримає лінію, захищає стрільців |
| 4 | швидкий ударний / літун | висока ініціатива, атакує стрільців |
| 5 | підтримка / маг | лікування, бафи, прокляття, магічна атака |
| 6 | елітний ударний | основна сила в середині гри |
| 7 | чемпіон | рідкісний, вирішує бій, часто великий 2×2 |

Відступи від шаблону дозволені (наприклад, у Ковена стрілець на 2 і маг на 5), але **кожна фракція повинна мати
стрільця, танка, швидкого юніта й підтримку**, інакше баланс розвалиться.

## 6. Що в кожного типу даних (поля)
- **UnitDef:** id, faction, tier, upgrade_of, attack, defence, min_dmg, max_dmg, hp, speed, initiative, shots, size (1|2),
  flying, abilities[], spells[] + mana, magic_resist, no_morale, weekly_growth, cost{}, exp, model, portrait, sounds{}.
- **AbilityDef:** id, handler (скрипт), params{}, ai_weight, icon, name_key, desc_key.
- **SpellDef:** id, school, level, mana_cost, target (ворог / союзник / клітинка / усі), area, base[4], per_power[4],
  effect (шкода / ефект з тривалістю / призив), duration_rule, icon, vfx.
- **OrderDef:** id, cost (очки командування), target, effect, params.
- **HeroClassDef:** id, faction, attribute_weights[4], skill_weights{}, starting_skills.
- **HeroDef:** id, class, portrait, specialization, starting_army, starting_spells.
- **SkillDef / PerkDef:** id, levels[3] з ефектами; perk: skill, required_level, effect.
- **ArtifactDef:** id, slot, bonuses{}, value, rarity.
- **BuildingDef:** id, faction, cost{}, requires[], effect (дохід / житло / гільдія / ринок…), dwelling_unit.
- **MapObjectDef:** id, footprint, visit_rule (один раз / щотижня / захоплення), reward, guard_value, value.
- **MapTemplateDef:** zones[], links[], players_min/max, size.
