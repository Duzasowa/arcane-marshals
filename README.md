# Arcane Marshals

Покрокова фентезі-стратегія в дусі «Героїв меча і магії 5»: герої-маршали, пригодницька карта, міста й тактичні бої
зі шкалою ініціативи. Godot 4.7 + GDScript.

**Стан:** план і проєктні документи (2026-11-23). Коду ще немає, тож починаємо з фази Ф0 у `PLAN.md`.

## Документи
| Файл | Що |
|---|---|
| `PLAN.md` | повний план фазами Ф0–Ф14 з чекбоксами |
| `docs/CONCEPT.md` | світ, родзинки, фракції, юніти, герої, магія |
| `docs/GAME_SKELETON.md` | усі екрани, системи, обсяг контенту, ролі юнітів, поля даних |
| `docs/MECHANICS.md` | формули й константи: бій, ініціатива, шкода, магія, економіка, генератор карт, ШІ |
| `docs/OPEN.md` | відкриті питання |
| `docs/reference/H5_MECHANICS_REFERENCE.md` | розбір механік HoMM5, лише для ідей і пропорцій |
| `assets/CREDITS.md` | джерела й ліцензії ассетів |
| `CLAUDE.md` | правила для Claude Code |

## Запуск
Після фази Ф0 команди будуть у `CLAUDE.md` (розділ «Запуск»).

## Важливо
Прототип тимчасово використовує приватні 2D-заглушки й звуки з власної копії HoMM5. Вони лежать **поза репозиторієм**
(`D:\Games\h5_placeholders`) і замінюються своїми у фазі Ф13. У цьому репозиторії немає жодного файлу гри HoMM5.
